# Security Policy

HardShell Core is designed to reduce operational security risk by structure:
- write operations are API-only
- authentication/authorization is enforced centrally
- private resources are masked as 404 when unauthenticated
- audit logs are stored in BigQuery

---

## Reporting a vulnerability

Please report security issues privately.

- Open a private advisory (GitHub Security Advisories), or
- Contact the maintainers via email (TBD)

We will respond as soon as possible and coordinate a responsible disclosure.
